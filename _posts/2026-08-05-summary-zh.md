## [ChainDrop 蠕虫攻陷 npm 超 1300 个包](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/) ⭐️ 9.0/10

自我传播的 ChainDrop 蠕虫已攻陷超过 1300 个 npm 包，包括 Keyv、Cacheable 等热门缓存库；攻击始于黑客接管维护者的 GitHub 账号。恶意版本通过正常的 GitHub Actions 流程发布，蠕虫会窃取凭证并感染其他维护者的包。 这是有记录以来规模最大的 npm 供应链攻击之一，受影响包合计月下载量超过 20 亿次，波及范围涵盖无数 Node.js 应用。安全机构建议安装过受影响版本的组织将系统视为已被攻破，轮换所有凭证并重建环境，凸显了开源依赖带来的系统性风险。 该蠕虫会部署 setup.mjs 投放器和 Math_Symbol.js 窃密脚本，在运行 `npm install` 时自动执行，窃取 GitHub、npm、AWS、Kubernetes 等令牌。StepSecurity 报告称在不到四小时内就有 444 个包、2212 个版本被投毒，npm-cache[.]com 域名可作为失陷指标；攻击仍在扩散。

telegram · zaihuapd · 8月5日 03:04

**背景**: ChainDrop 是 Shai-Hulud 蠕虫家族的一个变种，通过高度混淆的基于 Bun 的 JavaScript 载荷投递，并使用基于以太坊的 dead-drop C2 信道进行指挥与控制。针对 npm 的供应链攻击日益常见，因为许多项目大量复用依赖，一个被攻破的包可以在受害者无需任何直接操作的情况下，将恶意代码传播到成千上万的下游应用中。

Cloudflare 发布了 Cloudflare OS，这是一个基于其 Workers 无服务器平台构建的开放平台，面向代理（agent）、应用和工作场景。该公告重新构想了 Kenton Varda 早年的 Sandstorm 项目，并深度整合了 AI 与边缘计算。 这一公告表明 Cloudflare 正全面进入 agentic AI 平台竞争，将其边缘基础设施与 AI 原生工作流相结合。它可能为开发者提供一种无需管理服务器即可部署和管理 AI 代理与应用的新方式，但也引发了关于平台锁定的担忧。 Cloudflare OS 构建在 Cloudflare Workers 之上，社区分析指出它直接使用了 pi-agent 项目，而不是 Cloudflare 自家的 Agents SDK 和 Think/Flue 工具链。该平台被定位为面向工作的“操作系统”，提供连接器和 AI 能力，但也有批评者认为“OS”这一命名含义模糊。

## [LLM 0.32 新增推理轨迹、服务端工具与新模型](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 8.0/10

LLM 0.32 于 2026 年 8 月 4 日发布，新增在标准错误输出中显示推理轨迹、服务端提供方工具（OpenAI 的 CodeInterpreter 和 WebSearch）、内容寻址 SQLite 日志，以及对 GPT-5.6 系列的内置支持，并将 GPT-5.6 Luna 设为新的默认模型。llm-anthropic 插件也同步更新，增加了 WebSearch、WebFetch、CodeExecution 和 AnthropicMCP 工具。 这是 LLM 项目自最初发布以来最重要的一次版本更新，让命令行用户无需编写自定义代码即可查看模型推理过程并使用强大的服务端工具。它还推动了 OpenAI Responses API 的更广泛采用，并让针对任意 OpenAI 兼容端点执行一次性提示变得非常简单。 用户可以使用 -R/--hide-reasoning 隐藏推理输出，并通过服务端工具运行提示词，例如 `llm --tool CodeInterpreter 'Show current python and SQLite versions'`。新的 `llm openai endpoint` 命令可以针对任何 OpenAI 兼容端点运行一次性提示，且不写入日志。

rss · Simon Willison · 8月4日 23:58

## [交易所关停局域网线路 周边机房租金大涨](https://mp.weixin.qq.com/s/lH2IAcm1uX33Hw1H_EfPDg) ⭐️ 7.0/10

7 月 31 日晚起，沪深北交易所关停机房内局域网交易行情线路，机构接入统一改为广域网，且双向时延不得低于 2 毫秒，服务器须迁出交易所机房。此后，上海金桥、外高桥、张江等周边区域随即出现「抢机房」热潮，标准 4000 瓦金融机柜月租金从年初约 7000 元涨至万元上下。 这一政策变化直接重塑了中国高频交易基础设施格局，推高托管成本并改变时延生态。由于撮合遵循「价格优先、时间优先」原则，距离交易所的远近决定指令速度，强制迁出与 2 毫秒最低时延可能削弱对延迟敏感的量化策略的优势，并抬高行业进入门槛。 新规设定双向时延不得低于 2 毫秒，即便链路更快也必须人为拉长，这在一定程度上拉平了各方速度差距。金桥周边金融级第三方机柜仅数千个、供不应求；业内指出，真正依赖速度竞争的只是少数超高频策略，多家量化私募表示「跟着券商走」即可。

telegram · zaihuapd · 8月5日 14:44

**背景**: 时延是系统中从原因到结果之间的时间延迟，在金融交易中即使毫秒级差异也至关重要，因此托管和近端托管服务会把交易服务器放置在离交易所撮合引擎更近的地方。这类金融级托管服务正是以低时延优势为核心卖点，因为在「价格优先、时间优先」的规则下，更早到达的订单会优先成交。不过，托管价格高度受地理位置、电力成本和市场供给影响，这也解释了为何交易所强制服务器迁出后，周边金融数据中心集群的租金会大幅上涨。
